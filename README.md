# Codveda Data Analytics Internship

This repository contains the data analytics projects completed as part of my **Codveda Data Analytics Internship**.

## 📂 Projects

### Level 1

#### Task 1 – Data Cleaning
- Customer Churn dataset
- Data cleaning and preprocessing
- Handling missing values and duplicates
- Data type correction and data quality checks

#### Task 2 – Exploratory Data Analysis (EDA)
- Customer Churn dataset
- Exploratory data analysis
- Data visualization
- Identification of patterns and trends

### Level 2

#### Task 1 – House Price Prediction
- House price dataset
- Data preprocessing
- Regression analysis
- House price prediction

#### Task 2 – Time Series Analysis
- Stock price dataset
- Time series analysis
- Trend and pattern analysis
- Data visualization

### Level 3

#### Task 1 – Customer Churn Prediction
- Customer churn dataset
- Predictive modelling
- Model training and evaluation
- Churn prediction

#### Task 3 – Social Media Sentiment Analysis
- Social media text data
- Natural Language Processing (NLP)
- Sentiment classification
- Text analysis and visualization

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Natural Language Processing (NLP)
- Jupyter Notebook / Google Colab
